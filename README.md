# ShadowFox Python Development Internship Tasks

This repository contains all the tasks completed as part of the **ShadowFox Python Development Internship**, including **Beginner**, **Intermediate**, and **Advanced** level tasks.

All programs are written in Python and executed successfully.

---

## 1.Beginner Level Tasks

The Beginner folder contains Python programs covering basic programming concepts:

- **Variables**
  - Storing values and checking data types
  - Simple Interest calculation
  - Demonstration of Python reserved keywords (`for`)
- **Numbers**
  - Format function
  - Mathematical calculations
- **Lists**
  - List operations using the Justice League example
- **If Conditions**
  - BMI Calculator
  - City-to-country mapping
- **For Loops**
  - Dice simulation
  - Jumping jacks program

---

## 2.Intermediate Level Tasks

The Intermediate folder includes:

- **Web Scraper**
  - Extracts data from a website using `requests` and `BeautifulSoup`
- **Hangman Game**
  - Word guessing game with visual progress and limited attempts

These programs demonstrate practical Python usage and logic building.

---

## 3.Advanced Level Task

The Advanced folder contains:

- **Data Analysis Project**
  - Student marks dataset
  - Data analysis using `pandas`
  - Visualization using `matplotlib`
  - Calculation of total and average marks

This task demonstrates data handling, analysis, and visualization skills.
